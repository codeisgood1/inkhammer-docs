Keyboard shortcuts

Type to filter the list. Hovering any tool or button in Ink Hammer also shows its shortcut.

KeysWhat it does
VSelect tool
BPaint tool
PPen tool (paths, walls, cliffs, stairs)
THeight tool (terrain)
UBuild tool (rooms and buildings)
LLights tool
WWalls tool (walls, doors, windows)
NLabels tool
GGrid tool (turn and resize the snap grid)
EscCancel what you are doing, then back to Select
Ctrl+ZUndo
Ctrl+Y or Ctrl+Shift+ZRedo
Ctrl+NNew map
Ctrl+OOpen a map
Ctrl+SSave
Ctrl+Shift+SSave as
Ctrl+EExport
Ctrl+,Settings
Ctrl+QQuit
Ctrl+C / X / VCopy, cut, paste (works between maps)
Ctrl+Shift+C / VCopy an item's look, paste it onto others of its kind
Ctrl+DDuplicate
Ctrl+dragDrag out a copy
Ctrl+ASelect all
DelDelete the selection
Shift+clickAdd to or remove from the selection
Alt+clickPick the next thing in a stack
R / Shift+RRotate 15 degrees one way or the other
FMirror
[ and ]Scale the selection down or up; with a brush, brush size
HHide the selection
Ctrl+LLock the selection
Ctrl+GLink the selection (moves as one)
Ctrl+Shift+GUnlink
Arrow keysNudge (Shift for further)
Shift while placingKeep placing the same thing
Alt while placingIgnore the snap grid
OOpen or close the selected door or window
MMerge the selected rooms (Build tool)
Ctrl+B / I / UBold, italic, underline while typing a label
F1Fit the whole map in the window
Space+drag or middle mousePan
Mouse wheelZoom
Ctrl+Shift+AAsset Manager

In the Layers panel

These work while the Layers panel is in use and a layer (not an object) is picked.

KeyWhat it does
Ctrl+clickAdd a layer or object to the pick, or take it out
Shift+clickPick every row between the last click and this one
Ctrl+A / EscPick every layer / let go of the pick
Alt+Up / DownMove the picked layers up or down
Alt+Right / LeftInto the group above / out of its group
Ctrl+G / Ctrl+Shift+GGroup the picked layers / ungroup
Ctrl+DDuplicate the picked layers
Ctrl+C / VCopy the picked layers / paste them above the current one
F2Rename
DelDelete the picked layers
