Claude

Connect Claude

With the connection on, Claude (in the Claude desktop app) can build, check and export maps in Ink Hammer while you watch. Every change shows up live, and Ctrl+Z undoes it like your own edits.

What you need

The Claude desktop app for Windows and a Claude plan that can use connectors. Setup takes about ten minutes, once.

1. Install uv

uv runs the small connector program that ships in Ink Hammer's mcp folder. It brings its own Python, so you do not need to install Python. Open PowerShell from the Start menu and paste:

powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

When it finishes, close PowerShell. uv lands in C:\Users\you\.local\bin\uv.exe.

2. Turn on the Local API

In Ink Hammer, tick Tools > Local API for Claude. It stays on between runs. It only listens on your own computer and needs a private token, which Ink Hammer writes for the connector.

3. Add Ink Hammer to Claude

In the Claude desktop app open Settings > Developer > Edit Config. That opens claude_desktop_config.json.

Fill in the two boxes below and copy the result into the file.

Your Windows user name
Your Ink Hammer folder

Put this in the file, with your own Windows user name and Ink Hammer folder in the two paths (every backslash written twice). The guide in your browser (Help > User guide) can fill them in for you.

{
  "mcpServers": {
    "ink-hammer": {
      "command": "C:\\Users\\you\\.local\\bin\\uv.exe",
      "args": ["run", "--no-project", "--quiet", "C:\\Users\\you\\Documents\\Ink Hammer\\mcp\\ink_hammer_mcp.py"]
    }
  }
}

If the file already has an "mcpServers" section, add only the "ink-hammer": {...} part inside it, with a comma between it and the entry before.

4. Restart Claude

Quit the Claude app fully (right-click its icon by the clock, then Quit) and open it again. Ink Hammer's tools now show under the connectors (tools) button in a new chat.

Try it

With Ink Hammer open, ask Claude things like:

  • "Make a 30 by 20 map of a roadside tavern at dusk with a stable and a well."
  • "Add a campfire in the yard and turn the sun down to evening."
  • "Check the walls for gaps, then export gridless at 140 px and a Universal VTT file."

Claude drafts; you refine by hand, then export. Claude can also take screenshots of the map to check its own work.

Each Ink Hammer update brings a new connector in its mcp folder: quit and reopen Claude after updating so it loads the new tools (for example round rooms and object masks).

If it does not work

"Ink Hammer isn't answering"

Ink Hammer is closed, or the Local API is off. Open Ink Hammer and tick Tools > Local API for Claude.

"Refused the token"

Untick and tick Tools > Local API for Claude again, then ask Claude to retry.

Claude does not list the Ink Hammer tools
  • Check the paths in the config: every backslash is written twice (\\).
  • Check uv is where the config says: run uv --version in a new PowerShell window.
  • Quit Claude fully and reopen it; closing the window is not enough.
"Lost Ink Hammer during ..."

Ink Hammer stopped mid-task. Restart it; your work is in the autosave if it was not saved.

Help > Connect Claude in Ink Hammer shows where its token file is, if you need it.
